# Mi-Clase

Para iniciar:

```bash
npm install
npm run dev
```

La app usa el backend documentado en [documentacion.md](https://github.com/cayocft/backend-react/blob/master/documentacion.md).

Puedes iniciar sesión para crear publicaciones. El muro es público y permite reaccionar con seis tipos de reacción. Las publicaciones se pueden ver, pero no editar.
